## Краткое описание решений

### Средн.1 — задание 8: декоратор замера времени
Декоратор `measure_time` на `time.perf_counter()` с `functools.wraps`:
возвращает исходный результат функции, передаёт все аргументы,
измеряет время через `try/finally` (в том числе при исключении) и
сохраняет длительность последнего вызова в атрибуте `last_duration`.

### Средн.2 — задание 10: несколько функций через map
Функция высшего порядка `apply_functions(values, functions)` возвращает
список результатов применения каждой функции ко всем значениям
(каждая функция применяется через `map`): для `[1, 2, 3]` и функций
«квадрат», «+1» результат — `[[1, 4, 9], [2, 3, 4]]`.

### Средн.3 — задание 4: факториал через reduce
`factorial(n)` вычисляется свёрткой
`reduce(operator.mul, range(1, n + 1), 1)`; начальное значение 1 даёт
`0! = 1`; отрицательные и нецелые аргументы отклоняются.

### Повыш.1 — задание 8: CSV через map/filter
`process_csv(source, destination, min_score=60)` читает CSV
(`csv.DictReader`, UTF-8, `newline=""`), через `filter` оставляет записи
с баллом не ниже порога, через `map` преобразует запись (числовой балл
и поле `status`), результат пишется в отдельный файл через
`csv.DictWriter`. Пример данных: `data/students.csv`.

### Повыш.2 — задание 1: композиция функций
`compose(*functions)` возвращает композицию унарных функций с применением
справа налево: `compose(f, g)(x) == f(g(x))`. Композиция из одной
функции равна ей, пустая композиция — тождественная функция.
